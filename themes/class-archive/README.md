# Class Archive theme

The supported theme will be a Piwigo child/photo-first theme. It will keep
photos, chronology, albums and the mature viewer as first-class surfaces while
moving activity and account tools to secondary navigation.

Phase 0 uses the pinned Bootstrap Darkroom theme to validate derivative-first
grid markup and bundled PhotoSwipe integration markers. Browser layout,
lightbox interaction and touch behavior remain unverified. Product styling is intentionally deferred
until the platform, permission and lifecycle gates pass. No Piwigo Core template
will be modified.
