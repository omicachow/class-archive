# Security policy

Class Archive is a private-memory-space project. Do not post real class data,
credentials, claim/invitation values, database dumps or NAS details in public
issues, pull requests or discussions.

## Reporting a vulnerability

For a security issue in the code or deployment protocol, use a private GitHub
Security Advisory for the repository. Include the affected commit, a minimal
synthetic reproduction and the impact. Do not include real photos, names,
tokens or passwords. If a private advisory cannot be opened, contact the
repository maintainers through the GitHub account listed on the repository
instead of publishing exploit details.

The supported deployment remains localhost-only until the documented MediaGuard,
identity, backup, NAS and public-deployment gates are complete.
